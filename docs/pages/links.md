# Links page

Create links page

Links page path '/dashboard/links'

**On page must be components form directory './../../components/links/'** 

## Table/List all links:
- URL (truncated)
- Category/Tags
- Status (✅ Active, ❌ Broken, ⚠️ Warning, 🔄 Checking)
- Last Checked
- Clicks (if have analytics)
- Actions (Edit, Delete, Check Now)

- By status, category, date added:
- Search bar
- Bulk actions: Delete selected, Check selected
- Sort options
