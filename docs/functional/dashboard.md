# Dashboard Module

## Overview
Protected dashboard for managing links and viewing statistics.

## Components
- [DashboardLayout](../../components/dashboard/dashboard-layout.tsx) - Main wrapper with sidebar
- [Sidebar](../../components/dashboard/sidebar.tsx) - Navigation (desktop & mobile)
- [Header](../../components/dashboard/header.tsx) - Top header
- [StatsOverviewCard](../../components/dashboard/stats-overview-card.tsx) - Statistics grid

## Statistics Tracked
- Total links count
- Active links
- Warning links
- Broken links
- Checking links
- Recently added (today)
- Overall health percentage

- Responsive sidebar (mobile sheet menu)
