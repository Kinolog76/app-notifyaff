# Landing Page Module

## Overview
Marketing landing page with animated sections showcasing the product.

## Sections
- **Hero** - Main value proposition with CTA
- **Problem** - Pain points for influencers
- **Solution** - How LinkGuardian solves them
- **How It Works** - 3-step process
- **Features** - Key feature cards
- **Target Audience** - Ideal user profiles
- **Pricing Preview** - Plan tiers overview
- **FAQ** - Common questions with accordion
- **CTA** - Final call-to-action
- **Footer** - Links and social

## Components Location
[components/landing/](../../components/landing/)

## Animations
Uses Framer Motion for scroll-triggered animations and interactions.

## Theme
Supports light/dark mode with theme toggle in header.
